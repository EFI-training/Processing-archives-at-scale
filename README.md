# Processing Archives at Scale

This repository contains materials for the workshop **Processing Archives at Scale**.

The workshop introduces practical approaches to systematically organising and processing archival data, including images and text. All examples are demonstrated using Python.

## Overview

This workshop introduces participants to practical Python techniques for processing archival data at scale. Participants will learn how to:

1. Rename and organise folders and files.
2. Extract data from archival materials.
3. Generate metadata for archival datasets to support subsequent analysis.

The workshop is designed for beginners with some prior programming experience. Participants should have a basic understanding of Python, including:

- Fundamental Python data types.
- Installing and importing Python packages.
- Using functions.

The workshop is delivered as a single session.


### Getting ready
You can use Jupyter Notebook on the University's Noteable service, which requires no installation. You can also install Jupyter Notebook locally on your computer.


#### Accessing Python On Noteable

1. Open the login page [here](https://noteable.edina.ac.uk/login).
2. Login with your EASE credentials.
3. Select Standard Python 3 as a personal notebook server and press start.
4. Go to Git > Clone a Repository
5. Copy and Paste this repository URL. (The Project directory name will be filled in automatically, but you can change it if you want your folder in Notable to have a different name).
6. Click 'Clone'
   
Congratulations! You have now pulled the content of this repository to your Notable server space.

#### Installing Jupyter Notebook locally
1. Make sure you have Python installed. If you use Windows, I recommend installing [Anaconda](https://www.anaconda.com/download). For other operating systems, see [https://wiki.python.org/moin/BeginnersGuide/Download](https://wiki.python.org/moin/BeginnersGuide/Download).
2. If you use Anaconda, install Jupyter via Anaconda (if it is not installed yet). If not, you can use `pip` to install Jupyter Notebook. Type the following into your terminal:
```sh
python3 -m pip install notebook
```
3. Launch your Jupyter Notebook either via Anaconda Navigator, or via your terminal:
```sh
jupyter notebook
```
